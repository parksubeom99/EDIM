## 7. 이번에 바뀐 불변식

```
바뀐 것 : 견적 = 스냅샷 원가  →  견적 = 스냅샷 원가 × (1 + 마진율)
근거    : 회장님 결정 2026-09-30 (p66 EBIT 음수 해소)
범위    : 견적 단계만. 스냅샷 원가는 불변
마진율  : 요율표 샘플값 10% — 회사 정책 확정 시 파일 교체로 반영
영향    : e2e 6곳의 단언이 새 규칙으로 바뀜. ADR-003 원문은 보존 + 갱신 주석
```

PCR 세부에는 두 기준이 나란히 보인다(ccmd M-2 · N STEP 3):
- 원가 기준 한 줄: 재료비 + 인건비에 요율 간접비를 더한 기준 → **EBIT 2,193,185**
- 참고 줄: 스냅샷 원가 기준 이익 = 견적 − 스냅샷 원가 = **1,548,717**

어느 쪽이든 원가 ₩15,487,170 · 견적 ₩17,035,887 은 불변이다(e2e S80d · S80e).

생산 · 창고 · 품질 표는 **원가 계산이 읽지 않는다**(ccmd L 하드 가드 5) — p44 의 "공정비용 원가"는 이 때문에 없는 것으로 적었다.
