## 7. 이번에 바뀐 불변식

```
바뀐 것 : 견적 = 스냅샷 원가  →  견적 = 스냅샷 원가 × (1 + 마진율)
근거    : 회장님 결정 2026-09-30 (p66 EBIT 음수 해소)
범위    : 견적 단계만. 스냅샷 원가는 불변
마진율  : 요율표 샘플값 10% — 회사 정책 확정 시 파일 교체로 반영
영향    : e2e 6곳의 단언이 새 규칙으로 바뀜. ADR-003 원문은 보존 + 갱신 주석
```

기록: `docs/04-decisions/2026-09-19-business-architecture-ledger.md`(5절 표 한 줄 + 2026-10-01 절). 함께 밝힌 것: PCR 세부의 원가 기준 = 재료비 + 인건비(스냅샷 Overhead 제외) → EBIT 는 "견적 − 스냅샷 원가"와 다를 수 있음(표 밑 한 줄 · S80d 타이).

숫자(이번 실행): 원가 ₩15,487,170 · 견적 ₩17,035,887 · 견적 − 원가 ₩1,548,717 · PCR EBIT(Own acc. · Biz 1 · Biz 2) = 2,193,185 · 1,265,459 · 1,247,237.

| 단계 | 호스트 자원 | 킷에서 못 도는 이유 |
