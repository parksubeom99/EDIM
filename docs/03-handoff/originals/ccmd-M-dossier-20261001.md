- 기대값에 맞추려고 판정을 올리기 — 화면 경로 없이 `실동` 금지
- 운영 모드 e2e 실패 상태에서 머지
- 문서 PR 에 코드가 섞여 있는데 머지
- host-only e2e 단계를 **조용히** 건너뛰기 (출력에 남겨야 함)
- 볼륨을 `prune` 이나 와일드카드로 지우기 — 이름 정확 대조 후 개별 지정
- CI 실패 시 Auto-fix 켜기
- 신규 스키마 마이그레이션 (Tier B — 설계만 쓰고 보고)
- `git push --force` · main 직접 push
- ccmd L 범위 건드리기 (§10)
- 명령 블록 안에 `#` 로 주석 달기 (CMD 가 인자로 해석)
- e2e 에 고정 대기 넣기 → 상태 대기로
- 회장님 승인 없는 패키지 설치 (`pip install` · `winget` · `choco`)
