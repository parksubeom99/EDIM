# 규칙 R 항목 대조 — p42 · p43 · p44 · p69 (ccmd P STEP 2 · 2026-10-01 · CC 초안 — 엘 재측정 전)

> 원문 항목 목록 = ccmd P §2-2(엘이 EDIM.pdf 원문에서 뽑은 목록). 각 항목: **있음**(화면 경로 + e2e 단계 ID) · **없음**(필요한 입력) · **확장**(회장님 확정 확장 목록) · **애매**(덮는지 판단이 서지 않음 — 엘에게 넘김, 임의로 '있음' 처리하지 않음).

## 규칙 R (엘 확정 · 생성기 머리 주석 · page-map 머리와 같은 글)

```
R1. 청사진 쪽의 원문 항목을 전부 열거한다.
R2. 항목마다: 있음(화면 경로 + e2e 단계 ID) / 없음 / 확장(회장님 확정 확장 목록).
    확장 목록 = AR · XR · 증강 현실 · Digital Twin · Smart Factory · 실시간 설비 데이터 · 파트너 외부 로그인 포털
R3. '없음'이 0 이면 실동(샘플 자료면 실동(샘플)) · '없음'이 1 이상이면 부분 · 화면 0 이면 미착수.
R4. 판정 칸 옆에 '없음' 항목과 "필요한 입력: …"을 적는다.
```

기계 적용 메모: '애매'는 판정에서 '없음'으로 세지 않았다(엘 판정 대기). 애매를 '없음'으로 세면 결과가 바뀌는 쪽은 아래 각 표 끝에 적었다.
