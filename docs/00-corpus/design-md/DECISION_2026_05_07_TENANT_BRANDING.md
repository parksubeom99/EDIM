# Decision: Tenant Branding

Date: 2026-05-07

## 결정

EDIM은 SaaS 플랫폼이므로 회사별 로고와 회사명을 EDIM Core Shell에 표시한다.

Tenant Branding은 EDIM Core의 기본 기능으로 포함한다.

## 이유

한 사용자가 여러 회사, 협력사, 고객 조직에 소속될 수 있다.

따라서 사용자는 로그인 후 현재 어느 회사의 데이터에서 작업 중인지 명확히 알아야 한다.

회사 로고와 회사명은 단순 장식이 아니라 현재 Tenant Context를 보여주는 정보다.

## 초기 범위

- 회사명 표시
- 회사 로고 업로드
- Header 좌측에 로고 표시
- 로고가 없을 때 EDIM 기본 로고 표시
- Tenant Branding 설정 저장

## 향후 확장

- 문서용 로고
- 견적서/승인도서/기술자료의 회사 로고
- 회사 주소/전화번호/이메일
- 문서 머리글/바닥글
- 회사별 대표 색상
