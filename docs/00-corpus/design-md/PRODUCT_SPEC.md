# Product Spec

## 제품 비전

이 제품은 제조, 설비, 엔지니어링, 프로젝트 수주형 회사가 견적, BOM, 기술자료, 승인도서, 제작도면, 내부 업무 규칙을 하나의 SaaS 시스템에서 관리하도록 돕는 플랫폼입니다.

사용자는 전문 개발자가 아니어도 회사 업무에 맞는 필드, 양식, 승인흐름, 매크로를 설정할 수 있어야 합니다.

## 주요 사용자

- 회사 관리자: 사용자, 권한, 회사 설정, 커스터마이징 관리
- 영업/견적 담당자: 고객 요청, 프로젝트, BOM, 견적 생성
- 설계/기술 담당자: 품목, BOM, 기술자료, 제작도면, 변경관리
- 승인자: 견적, 도면, 문서, 변경 요청 검토 및 승인
- 경영/관리자: 진행 현황, 견적 금액, 승인 지연, 수주 전환율 확인

## 주요 모듈

### 1. SaaS/회사 관리

- 회사별 데이터 분리
- 사용자 초대
- 역할과 권한
- 회사별 기본 설정
- 감사 로그

### 2. CPQ

- 고객 및 프로젝트 관리
- 품목 선택
- BOM 구성
- 옵션/규칙 기반 구성
- 원가, 마진, 할인, 견적 금액 계산
- 견적서 생성
- 기술자료 및 승인도서 생성

### 3. PLM

- 품목 마스터
- 품목 버전/리비전
- BOM 버전 관리
- 변경 요청
- 제작도면 생성 흐름
- 도면/문서 파일 관리

### 4. ERP 커스터마이징

- 회사별 커스텀 필드
- 화면 레이아웃 설정
- 양식 템플릿
- 승인 워크플로우
- 업무 규칙
- 상태값과 코드값 관리

### 5. AI 매크로

- 사용자의 자연어 요청을 매크로 초안으로 변환
- 반복 업무 자동화 제안
- 문서 초안 생성
- 견적/BOM 입력 보조
- 관리자 검토 후 적용

## MVP 후보

첫 MVP는 다음 흐름을 목표로 합니다.

1. 회사 계정 생성
2. 사용자 로그인
3. 고객 등록
4. 프로젝트 등록
5. 품목 등록
6. BOM 구성
7. BOM 기반 견적 생성
8. 견적 상태 변경
9. 기본 견적서 출력용 데이터 생성

MVP에서는 복잡한 도면 자동 생성, 고급 AI 매크로 실행, 완전한 ERP 커스터마이징은 제외하고 구조만 열어둡니다.

## 아직 정해야 할 질문

- 1차 대상 업종은 무엇인가?
- BOM은 몇 단계까지 필요한가?
- 견적 계산 공식은 어떤 항목으로 구성되는가?
- 제작도면은 어떤 형식으로 생성해야 하는가?
- 승인도서는 PDF, Word, Excel 중 무엇이 먼저 필요한가?
- 회사별 커스터마이징은 필드부터 필요한가, 화면부터 필요한가?
- AI 매크로는 어떤 반복 작업을 가장 먼저 자동화해야 하는가?
