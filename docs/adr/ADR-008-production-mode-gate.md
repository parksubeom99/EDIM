# ADR-008: 운영 모드 e2e 를 머지 게이트에

- **상태**: 확정 (2026-09-27)

## 상황
개발 모드 e2e 287단계가 모두 통과하던 앱이 운영 빌드에서 HTTP 500 으로 무너졌다(T-01). 개발 모드와 운영 모드는 캐시 · 번들 · 프리렌더가 다르다.

## 결정
머지 게이트 = typecheck → 단위 → DB 초기화 후 DB 검증 11종 → e2e 개발 모드 1회 + **운영 모드 1회**(`next build → start`, 실행 중 `pg_stat_activity` 기록) → ff 머지 → 머지된 main 에서 한 번 더. 배포 킷 컨테이너에서도 e2e 를 돌린다.

## 검토한 대안
- 개발 모드만
- 수동 스모크

## 결과 — 얻은 것
운영에서만 나는 결함을 머지 전에 잡는다(T-05 도 이 게이트가 잡음).

## 결과 — 치른 것
게이트 시간이 길어진다(수십 분).

## 검증
운영 모드 e2e 348/348 · 동시 연결 14~17
