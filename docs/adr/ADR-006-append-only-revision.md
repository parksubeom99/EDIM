# ADR-006: 코드 개정은 append-only (DB 권한)

- **상태**: 확정 (0005 · 0003)

## 상황
코드 개정(Rev A → B)은 감사 근거다. 앱 버그나 운영자 실수로 이력이 고쳐지면 추적이 끊긴다.

## 결정
`code_revision` 에 앱 역할은 `SELECT, INSERT` 만 받고 `UPDATE, DELETE` 는 REVOKE 한다(0005 — 구조상 append-only). 매크로는 등록부 규칙(초안 → 승인 → 개정)으로 관리하며, 반려된 초안이 개정 번호를 먹던 결함을 T-04 에서 발견 · 수리했다. 발행 문서 · 발주 구매 요청의 잠금은 트리거(0008 · 0009 · 0010)가 맡는다.

## 검토한 대안
- 소프트 삭제 플래그

## 결과 — 얻은 것
이력이 DB 수준에서 불변이다.

## 결과 — 치른 것
잘못 만든 개정도 지울 수 없다 → 새 개정으로 되돌린다.
