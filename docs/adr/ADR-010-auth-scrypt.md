# ADR-010: 비밀번호 = Node 내장 scrypt · SSO 는 자리만

- **상태**: 확정 (0032)

## 상황
공개 저장소 · 데모 배포를 앞두고 이메일만으로 들어가는 개발용 로그인을 끝내야 했다.

## 결정
`crypto.scrypt` + `timingSafeEqual` · 형식 `scrypt$N$r$p$salt$hash` · 해시 없는 계정은 개발 모드에서만 이메일 로그인 · 5회 실패 시 잠시 잠금(429) · 오류 문구는 계정 존재를 흘리지 않음. SSO 는 고객 IdP 가 필요해 설정 자리만.

## 검토한 대안
- bcrypt 등 네이티브 모듈 — Windows 빌드 부담
- 외부 인증 서비스

## 결과 — 얻은 것
외부 의존 0.

## 결과 — 치른 것
잠금 카운터가 서버 메모리라 다중 인스턴스에선 공유 저장소가 필요하다(기록된 후속 과제).

## 검증
auth 단위(잘린 해시 거부 포함) · e2e S0a~S0d
