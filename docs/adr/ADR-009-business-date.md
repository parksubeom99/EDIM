# ADR-009: '오늘'은 회사 시간대 한 곳에서만

- **상태**: 확정

## 상황
단가 이력의 '현재 유효 단가'를 UTC 날짜로 판정했더니, 한국 시간 00~09시에 오늘 단가가 '예정'으로 보였다(T-02).

## 결정
날짜 판정은 `app/lib/today.ts` 의 `businessToday()` 하나로만(회사 시간대 `EDIM_TZ`, Intl 기반). 다른 곳에서 `new Date().toISOString().slice(0,10)` 금지.

## 검토한 대안
- 곳곳에서 날짜 계산

## 결과 — 얻은 것
시간대 버그가 한 곳에만 존재할 수 있다.

## 결과 — 치른 것
모든 날짜 코드가 이 함수를 거쳐야 한다(리뷰 규칙).

## 검증
새벽 경계 단위 테스트(KST 00:21 → 당일)
