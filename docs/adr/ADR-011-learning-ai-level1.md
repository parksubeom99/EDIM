# ADR-011: 학습 AI 1수준 = 결정론 공식 탐구 + 사람 승인 라벨

- **상태**: 확정 (0033 · 2026-09-29)

## 상황
회사 도면 수백 장에는 '전장 = 구획 길이의 합' 같은 규칙이 숨어 있다. 이를 찾아 마스터 규칙으로 바꾸면 도면 수백 장이 규칙 한 줄이 된다. 다만 블랙박스 모델이 만든 규칙은 제조 현장이 믿지 않는다.

## 결정
1수준은 설명 가능한 방법만 쓴다: DXF 발췌 → 정렬화(동의어 · 단위 · 구획 · RCCS 슬롯 사전) → 특징 3개 이하 조합의 최소제곱 탐구 → Macro DSL 로 표현 · 검증 → **관리자 승인 = 라벨** → 승인분만 회사 DB 로 단방향 투영. 합격 기준은 업무 영향 기준(제작 공차 1 mm · 어긋남 5 % 이하 · 근거 10장 이상). 도구마다 `validate → authorize → run`, 쓰기 도구는 승인 관문.

## 검토한 대안
- 신경망 회귀 — 설명 불가 · 소량 데이터에 과적합
- LLM 에게 공식 추론 — 재현 불가

## 결과 — 얻은 것
찾은 공식이 그대로 DSL 이라 사람이 읽고, 검증기가 검사하고, 실행기가 돌린다.

## 결과 — 치른 것
비선형 · 조건부 규칙은 1수준 밖(2수준 과제).

## 검증
샘플 도면 68장 + 기술문서 표에 숨긴 공식 3개 복원(최대 오차 0 mm) · 잡음 도면 3장 검출 · 미정렬 0 · 구조 유사도 1.00 · `learning:test` 24/24(역류 · 권한) · e2e S72a~h
