# ADR-002: LLM 은 빌드 타임 번역기, 런타임은 결정론

- **상태**: 확정

## 상황
도메인 전문가(비개발자)가 엑셀 매크로 수준의 계산을 직접 만들고 싶어 한다. LLM 이 도와주기 좋지만, 런타임에 LLM 이 답을 만들면 같은 입력에 다른 견적이 나올 수 있고 원인을 재현할 수 없다.

## 결정
두 시계를 분리한다. 빌드 타임: 자연어 → (LLM 자리) → Macro DSL → 정적 검증 · 시험 실행 → 역번역(흐름도 · 설명, LLM 없음) → 사람 승인. 런타임: 승인된 DSL 만 결정론 실행기로 돈다. 확정 문법은 DSL(AI 0), 위치 발췌는 주소 해석기(AI 0), 진짜 새 계산 한 구간만 빌드 타임 LLM.

## 검토한 대안
- 런타임 LLM 호출 — 비용 · 지연 · 비재현
- LLM 없이 수식 편집기만 — 비개발자 진입 장벽

## 결과 — 얻은 것
비용 0 · 지연 0 · 재현 100 % · 환각이 견적에 들어갈 경로가 구조적으로 없다. 역번역 덕분에 비개발자가 AI 산출물을 읽고 판정할 수 있다.

## 결과 — 치른 것
DSL 표현력 한계(v1 = 관측 함수 5 + 엑셀 코어 8). DSL 로 안 되는 계산은 Special Tool Box(별도 과금)로 보낸다.

## 검증
`macro-dsl` 54 · `macro-verify` 19 · `macro-compile` 13 · `macro-registry` 15 단위 · `macro:test` · e2e 매크로 검증 → 초안 → 승인 단계
